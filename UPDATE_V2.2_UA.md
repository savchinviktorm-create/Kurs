# Оновлення Telegram Course Platform v2.1 → v2.2

Версія **2.2** додає дві великі функції без зміни існуючого прогресу користувачів:

1. **Професійні персональні сертифікати після завершення курсу.**
2. **Керований пробний доступ (trial) до платного курсу.**

Оновлення зроблене адитивно: поточні користувачі, курси, прогрес, покупки, підписки, Spaces і медіа не видаляються.

---

## 1. Спочатку оновіть Supabase

Це важливо: **SQL краще виконати ДО завантаження нового коду у GitHub/Vercel**. Старий v2.1 спокійно працює після цієї міграції, а новий v2.2 уже очікує нові таблиці.

Відкрийте:

**Supabase → ваш проєкт → SQL Editor → New query**

Відкрийте файл:

`supabase/migrations/004_certificates_and_trials.sql`

Скопіюйте весь його вміст у SQL Editor і натисніть **Run**.

Очікуваний результат: запит виконався без помилки.

### Що створює 004

- налаштування trial у таблиці `courses`;
- налаштування сертифіката у таблиці `courses`;
- `course_trials` — одноразові пробні доступи;
- `course_certificates` — видані сертифікати;
- індекси та RLS для нових таблиць.

**001, 002, 003 та FRESH_INSTALL.sql повторно запускати НЕ потрібно.**

---

## 2. Оновіть код у GitHub

Архів `telegram-course-platform-v2.2.zip` — це повний проєкт, а не лише patch.

Якщо ви оновлюєте тим самим способом, що v2.1:

1. Розпакуйте архів на комп'ютері.
2. Відкрийте папку `telegram-course-platform-v2.2`.
3. Завантажте її **вміст** у корінь того самого GitHub-репозиторію.
4. Замініть файли, які GitHub запропонує замінити.
5. Не створюйте у репозиторії зайвий рівень `telegram-course-platform-v2.2/telegram-course-platform-v2.2/...`.
6. `.env` у GitHub не потрібний. Ваші секрети залишаються у Vercel Environment Variables.

Після commit Vercel має автоматично почати новий Deployment.

---

## 3. Перевірте Vercel

Відкрийте:

**Vercel → ваш проєкт → Deployments**

Новий deployment має отримати статус **Ready**.

У v2.2 додано npm-залежність `qrcode`. Vercel встановить її автоматично з `package.json`. Нових Environment Variables для v2.2 не потрібно.

BotFather, Mini App URL, webhook і поточні Telegram-налаштування змінювати не потрібно.

# Налаштування пробного доступу

Відкрийте Mini App під власником:

**⚙ Адмінка → Курси → потрібний курс**

У редакторі з'явиться новий блок **«Пробний доступ»**.

Для прикладу рекомендую:

- **Увімкнути безкоштовний пробний період** — так;
- **Тривалість, днів** — `5`;
- **Максимум кроків у trial** — `3`;
- **Ціна назавжди** — `99 ⭐`.

Потім натисніть **«Зберегти все»**.

## Як працює trial

- користувач бачить кнопку **«Спробувати безкоштовно 5 дн.»**;
- trial стартує лише після натискання цієї кнопки;
- trial зберігається на сервері за `Telegram ID + course_slug`;
- повторно отримати trial з іншого телефона або після перевстановлення Telegram не можна;
- якщо встановлено 5 днів + 3 кроки, доступ припиняється за тією умовою, яка настане першою;
- після завершення trial прогрес НЕ скидається;
- користувач бачить пропозицію **«Продовжити назавжди — 99 ⭐»**;
- після оплати він продовжує з того самого місця;
- якщо для Space задано `price_override_stars`, у paywall використовується саме ціна цього Space.

### Якщо потрібен trial лише за часом

Залиште поле **«Максимум кроків у trial»** порожнім.

### Якщо курс безкоштовний

Trial автоматично не використовується.

# Налаштування сертифіката

У тому самому редакторі курсу є блок **«Сертифікат після завершення»**.

Увімкніть:

**«Видавати сертифікат після завершення»**.

Далі можна налаштувати:

- підзаголовок, наприклад `Сертифікат про завершення курсу`;
- ім'я підписанта — необов'язково;
- посаду/роль підписанта — необов'язково;
- **QR-код та публічна перевірка справжності** — рекомендую залишити увімкненим.

Назву курсу, дату завершення, бренд і логотип Space система підтягує автоматично.

---

## Що бачить користувач після останнього кроку

Після фактичного завершення курсу з'являється блок **«Ваш сертифікат»**.

Користувач:

1. вводить ПІБ;
2. підтверджує правильність написання;
3. натискає **«Створити сертифікат»**.

Після цього доступні:

- **Переглянути**;
- **Зберегти PDF**;
- **Поділитися**;
- **Виправити ПІБ** і перевипустити той самий сертифікат без створення дубля.

Сертифікат має:

- A4 landscape;
- біло-кремову преміальну палітру;
- золоту рамку та акценти Space;
- бренд Space;
- ПІБ;
- назву курсу;
- дату завершення;
- унікальний номер формату `PPC-2026-...`;
- QR-код для перевірки справжності;
- необов'язковий підпис автора/керівника.

Сертифікат не заявляє про державну чи міжнародну акредитацію. Це сертифікат про завершення курсу на платформі.

# «Мої сертифікати»

Після отримання хоча б одного сертифіката на головному екрані Mini App з'являється кнопка **🎓 Сертифікати**.

Там користувач бачить усі свої сертифікати та може:

- відкрити сторінку перевірки;
- повернутися до відповідного курсу.

Публічна сторінка `/verify/<код>` показує тільки дані, необхідні для перевірки сертифіката: ПІБ, курс, дату та номер.

---

# Як перевірити все без ризику

Рекомендований тест:

1. Створіть тестовий платний курс на 3 кроки.
2. Ціна: `99 ⭐`.
3. Trial: `2 дні`, максимум `1 крок`.
4. Сертифікат: увімкнено.
5. Зайдіть тестовим Telegram-акаунтом.
6. Натисніть «Спробувати безкоштовно 2 дн.».
7. Пройдіть 1 крок — наступний має показати paywall.
8. Для повного тесту видайте тестовому користувачу доступ через адмінку або зробіть тестову оплату.
9. Завершіть усі 3 кроки.
10. Введіть тестове ПІБ і створіть сертифікат.
11. Перевірте preview, PDF, sharing і QR/сторінку verify.

# Важливо про існуючі курси

Після міграції обидві нові функції **за замовчуванням вимкнені**.

Тобто існуюча «Технологія змін» та інші курси не змінять поведінку самі по собі. Ви вмикаєте trial і сертифікат окремо для кожного курсу через адмінку.
