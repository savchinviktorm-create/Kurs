# Оновлення Platform v2 → v2.1

Це оновлення потрібне для професійного імпорту курсу **«Технологія цифрового мільйонера»** і нових Course Package v2.

## Що додається

- інтерактивний `quiz` блок;
- серверне збереження відповідей і checklist;
- обов'язкові критерії/самоперевірка перед завершенням заняття;
- коректне відображення image-блоків у захищеному плеєрі;
- `self_paced` інтерфейс без «тижнів» та штучного щоденного очікування;
- індивідуальні фінальний і return-екрани;
- імпорт `logo_file` та `cover_file` прямо з Course Package ZIP;
- редагування quiz у адмінці;
- показ обкладинки курсу в каталозі.

## Оновлення існуючого проєкту

1. Завантажте в GitHub вміст архіву `telegram-course-platform-v2.1.zip`, замінивши файли поточного v2.
2. У Supabase → SQL Editor виконайте **лише**:
   `supabase/migrations/003_course_learning_experience.sql`
3. Дочекайтеся нового Vercel deployment зі статусом Ready.
4. Відкрийте Mini App і перевірте, що `/admin` працює.
5. В адмінці: **Імпорт → digital-millionaire-course-package-v2.zip**.
6. Після успішного імпорту відкрийте курс в адмінці, перевірте ціну й доступ. Курс навмисно імпортується як чернетка і прихований у `pkk`.
7. Для публікації увімкніть `Курс опублікований`, потім у Space `pkk` поставте галочку показу цього курсу.

## Важливо

- `001_initial.sql`, `002_platform_admin.sql` і `FRESH_INSTALL.sql` повторно не запускайте на чинній базі.
- `003_course_learning_experience.sql` не видаляє користувачів, спроби, платежі або прогрес.
- Якщо у Vercel задано `COURSE_IMPORT_MAX_BYTES=4000000`, готовий пакет проходить ліміт: його розмір приблизно 3.43 MB.
