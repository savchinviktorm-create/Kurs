# Швидкий чекліст запуску

- [ ] Розпакувати ZIP і завантажити файли в GitHub.
- [ ] Створити Telegram-бота і зберегти Bot Token.
- [ ] Створити Supabase.
- [ ] Виконати `supabase/migrations/001_initial.sql` у SQL Editor.
- [ ] Створити Vercel-проєкт із GitHub.
- [ ] Додати всі production environment variables.
- [ ] Зробити deploy і отримати HTTPS URL.
- [ ] Локально виконати `npm install`.
- [ ] Виконати `npm run verify:course`.
- [ ] Виконати `npm run seed`.
- [ ] Виконати `npm run setup:telegram`.
- [ ] Відкрити `/start` у боті й перевірити Mini App.
- [ ] Перевірити, що курс безкоштовний.
- [ ] Зробити тестовий донат у Telegram test environment перед production.
- [ ] Вказати реальний контакт у `/paysupport`.
